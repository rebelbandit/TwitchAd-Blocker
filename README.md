TwitchAd Seamless

Requirements:
- Tampermonkey or Violentmonkey
- Disable other Twitch ad-blocking userscripts/extensions that modify the player

Features:
- VAFT2 ad blocking
- popout → autoplay fallback
- automatic freeze detection
- quality-bounce recovery
- pause/play fallback for Source-only streams
- discreet top-right status notifications
- persistent diagnostic log

Useful console commands:
window.rbVAFT.status()
window.rbVAFT.stats()
window.rbVAFT.log()
window.rbVAFT.clearLog()
window.rbVAFT.recover()
